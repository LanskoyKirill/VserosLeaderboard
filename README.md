# VserosLeaderboard

Независимый рейтинг основного этапа Всероссийской олимпиады по искусственному интеллекту 2026.

**Сайт:** https://lanskoykirill.github.io/VserosLeaderboard/  
**Репозиторий:** https://github.com/LanskoyKirill/VserosLeaderboard

## Данные

- 759 аккаунтов из рейтинга первого тура, 168 участников второго тура.
- Первый тур: опубликованные All Cups баллы за A, B и C (максимум 900).
- Второй тур: расчётные баллы `600 × (169 − место) / 168` по 168 строкам сохранённого рейтинга.
- Итоговый топ-300 расчётный и **не является официальным протоколом**. Private-метрики второго тура округлены до 0,001; при точных совпадениях итоговые баллы и порядок могут отличаться.
- Данные сохранены 18 октября 2026 года, около 17:30–17:48 МСК.

## Файлы

- `index.html` — сайт и таблица результатов;
- `style.css` — адаптивное оформление;
- `data.js` — локальные данные для работы сайта без API;
- `app.js` — фильтры, поиск, пагинация, подробности;
- `top_300.csv` — расчётный топ-300;
- `all_759.csv` — все участники;
- `round1_759.csv`, `round2_168.csv` — рейтинги туров;
- `leaderboard.json` — полный набор данных в JSON.

## Публикация GitHub Pages

Загрузите файлы в корень ветки `main`. В **Settings → Pages** выберите **Deploy from a branch → main → / (root)**. Все пути относительные, поэтому проект работает на GitHub Pages и локально (через `index.html`).

Не публикуйте исходные HTML-файлы All Cups: в них могут содержаться данные аккаунта, профиля и сеансовые токены. В этом проекте доступны только конкурсные логины и результаты.
