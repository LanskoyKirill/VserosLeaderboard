# ✳ Орбита 2026 — рейтинг основного этапа олимпиады по ИИ

Независимый статический сайт с топ-300 по **двум турам** основного этапа Всероссийской олимпиады по искусственному интеллекту 2026 (All Cups). Сохранённые данные: **18 октября 2026**, около 17:30–17:48 МСК.

**[Открыть сайт](./index.html)** · [Топ-300 CSV](./data/top_300.csv) · [Все 759 результатов](./data/all_759.csv)

## Возможности

- Общий топ-300; отдельные таблицы первого и второго туров.
- Поиск участника по логину среди всех 759 строк (при вводе автоматически ищет во всём наборе, даже если включён топ-300).
- Подробная карточка: задачи A, B, C; сумма первого тура, место и private-метрика второго тура.
- Оценка второго тура и возможная верхняя граница при совпадениях округлённой метрики.
- Мобильная вёрстка, никаких внешних библиотек, аналитики и API. Работает без серверной части и подключения к интернету.

## Опубликовать бесплатно через GitHub Pages

1. Создайте **публичный** GitHub-репозиторий, например `ai-olympiad-2026-leaderboard`.
2. Распакуйте архив и загрузите **содержимое** папки проекта в корень репозитория: `index.html`, `assets/`, `data/`, `.nojekyll`, `README.md`.
3. На GitHub откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку `main`, директорию `/ (root)` и сохраните.
4. Адрес сайта обычно будет `https://ВАШ-ЛОГИН.github.io/ai-olympiad-2026-leaderboard/` после публикации.

Можно также открыть `index.html` локально двойным нажатием. **Не загружайте в GitHub исходные сохранённые HTML-файлы All Cups!** Они могут содержать конфиденциальные данные профиля и сеансовые токены. В этот проект включены только логины участников и результаты соревнования.

## Источники и расчёт

- [All Cups — рейтинг первого тура](https://cups.online/ru/rounds/1805/leaderboard), 4 сохранённые страницы, **759** строк, включая результаты 0 баллов.
- All Cups — private leaderboard задания второго тура, 5 сохранённых страниц, **168** строк. Все 168 логинов найдены в результатах первого тура.
- [Правила первого тура](https://ai.edu.gov.ru/main): три задачи A, B, C, до 300 баллов за каждую.
- [Правила второго тура](https://ai.edu.gov.ru/main/proctoring): одна задача, до 600 баллов, баллы = `600 × K / N`, где `N` — число участников с зачтёнными решениями, `K` — число участников с метрикой не больше метрики данного участника, включая его самого.

**Первый тур:** используем готовую сумму `round1` и баллы за A/B/C ровно в том виде, в каком они были отображены All Cups. Не пересчитываем по трём округлённым значениям задач, поскольку итоги и суммы отличаются на доли балла из-за округления.

**Второй тур:** для участника с местом `r` из 168 рассчитываем `600 × (169 - r) / 168`. Для не участвовавших (отсутствующих в рейтинге второго тура) — `0`. Рейтинг второго тура показывает округлённые до трёх знаков метрики. Если два участника имеют одинаковую **неокруглённую** метрику, они должны получить один и тот же балл. Точная метрика в сохранённых файлах неизвестна. Поэтому:

- `round2_est` — порядковая оценка по опубликованному месту, нижняя граница при возможных точных равенствах.
- `round2_max` — верхняя граница: значение лучшего места среди участников с одинаковой **отображаемой** метрикой.
- `total_est = round1 + round2_est`; `total_max = round1 + round2_max`.
- Порядок участников строится по `total_est`, при совпадении — по месту первого тура. В скобках/сносках отмечаются потенциально затронутые строки. Это **оценочный рейтинг**, не подтверждённый оргкомитетом.

Часть строк с одинаковой отображаемой метрикой может в действительности иметь разные точные значения. Разница `total_max - total_est` — **не доказанная поправка**, а диапазон возможных баллов. По этим данным состав первой трёхсотки устойчив относительно такой поправки, хотя порядок отдельных участников может измениться.

Проверка: всего 759 различных логинов первого тура, все 168 второго тура найдены в первом, дубликатов логинов нет, по 4 страницам первого тура нет пропущенных позиций с 1 по 759.

## Структура проекта

```text
index.html             Страница сайта
assets/style.css       Оформление и адаптивная вёрстка
assets/app.js          Поиск, переключение туров, таблица, модальное окно
assets/data.js         Встроенные данные без fetch() — работают локально
data/                 JSON и CSV для повторного использования
data/top_300.csv       Итоговый оценочный топ-300
data/all_759.csv       Полный общий рейтинг
data/round1_759.csv    Результаты первого тура
data/round2_168.csv    Результаты второго тура
.nojekyll              Корректная публикация через GitHub Pages
```

## Важное замечание

Сайт и CSV **не являются официальными итогами олимпиады**. Решения могут быть аннулированы по результатам проверки; оценки второго тура зависят от точного значения private-метрик и состава зачтённых решений. Сайт не собирает никаких данных пользователей.

Дизайн и код этого аналитического проекта независимы от All Cups и организаторов олимпиады.
