Как рассчитаны баллы

Тур 1: баллы задач A, B, C и итог за первый тур взяты прямо из сохранённого рейтинга All Cups. Тур 2: оценка = 600 × (169 − место) / 168. Это следует перцентильному правилу для 168 зачтённых результатов. Отсутствие в рейтинге второго тура = 0 баллов.

Второй тур показывает private-метрику с округлением до трёх знаков. При действительно равных исходных метриках участники получают одинаковый, более высокий балл. Поэтому для затронутых строк показана возможная верхняя граница; точные результаты без полной точности метрики не гарантированы. Это не официальный итоговый рейтинг: жюри может изменить результаты после проверок.
